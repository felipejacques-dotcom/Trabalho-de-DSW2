CineMatch — API REST

Backend do sistema de catálogo, favoritos e avaliações de filmes.

Consulte a documentação completa no arquivo API.md do repositório.

Rotas disponíveis

  • POST /usuarios — cadastro
  • POST /usuarios/login — login e JWT
  • GET /usuarios/perfil — perfil (JWT)
  • GET /filmes e GET /filmes/:id — catálogo público
  • POST /filmes, PUT /filmes/:id, DELETE /filmes/:id — gerenciamento (administrador)
  • GET /favoritos, POST /favoritos/:filme_id, DELETE /favoritos/:filme_id — favoritos (JWT)
  • GET /avaliacoes/filme/:filme_id — listar avaliações
  • POST /avaliacoes/:filme_id, PUT /avaliacoes/:id, DELETE /avaliacoes/:id — avaliações (JWT)

As rotas protegidas recebem Authorization: Bearer TOKEN.
